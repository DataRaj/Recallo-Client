# Recallo identity candidates

**Latest revision:** open [the full-name identity](wordmark-system/index.html). It contains a new complete-name wordmark, visible terracotta/ink palette, usage rules, placement studies, a share-card export and a React component handoff. Earlier candidates below are retained as research history.

Open `index.html` directly in a browser, or visit `/brand/index.html` while the application is running. The comparison page includes all five identities, native-size previews, background toggles, individual sheets, mockups and download links. No build is required.

## Recommendation

**01 — Return R (89/100)** is the preferred direction. The initial gives the symbol an immediate connection to Recallo; the returning foot carries through into the custom lettering. Its weakness is the crowded field of R monograms, and some of its character disappears in the simplified 16px cut.

**03 — Retrace (83/100)** is the strongest alternative. Its stepped return path has a clear silhouette and reliable small-size performance. It can also read as a numeral 2, so it needs the wordmark alongside it while recognition develops.

The other contenders are **02 — Held quotation (78)**, **04 — Margin ligature (75)** and **05 — Binding fold (80)**. Detailed rationale, geometry, limitations and weighted scores appear in the comparison page and each identity sheet. Scores are design judgments, not measured audience recognition or legal clearance.

## Exports

Each `concept-0N/` folder contains the same set:

- `primary.svg`, `light.svg`, `dark.svg` and `monochrome.svg`: complete symbol and custom wordmark lockups; PNG previews accompany them.
- `wordmark.svg`, `symbol.svg`, `symbol-dark.svg`: independent outlined artwork.
- `favicon.svg` and `favicon-16.svg`: simplified 16px drawing. `favicon-32.svg` uses a separately snapped drawing. Both sizes have PNG exports; `favicon-dark.svg` is the reverse micro version.
- `app-icon.svg`, `app-icon-light.svg`, `app-icon.png`: balanced application icon, with the PNG at 512×512.
- `symbol-{16,24,32,64,512}.png` and matching `symbol-dark-*` files: native-size raster inspection set.
- `identity-sheet.svg/.png` and `mockups.svg/.png`: geometry, palette, evaluation and navigation/browser/meeting placement studies. Mockups are illustrative placement studies, not screenshots proving application integration.

All production SVG lettering and symbols are filled vector paths, without embedded bitmaps or font dependencies. Presentation labels on boards and sheets use system text.

## Reproduction

From the repository root, run:

```sh
python3 design/brand/generate.py
python3 design/brand/build_review.py
python3 design/brand/validate.py
```

Requires Python 3 and ImageMagick with SVG rendering support. No application dependencies were added. Browser evidence is a separate local Chromium check, not regenerated by these commands.

See `RESEARCH.md` for sources and positioning, `VALIDATION.md` for checks and limitations, and `validation.json` / `browser-checks.json` for recorded results. The ZIP includes these assets plus the source generators. Existing application branding remains unchanged; none of these candidates is selected or integrated.
