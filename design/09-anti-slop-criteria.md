# Review criteria specific to Recallo

## Release blockers

- Unsupported claims, invented customer evidence or mislabeled product captures.
- Broken create/join/login routes, locale loss, nonfunctional preview controls.
- Invisible keyboard focus, inaccessible dialog/menu, missing labels or unusable compact layout.
- A hero that communicates only video calling, with no visible link to a meeting record.
- Unreadable product/text scale, unexpected horizontal overflow, essential content hidden behind motion.

## Composition corrections

- If two adjacent sections use the same equal-card layout, restructure one around its actual information.
- If a line, marker, badge or UI fragment has no relationship to a conversation, source or outcome, remove it.
- If the same decision is repeated, the repetition must demonstrate the transition from speech to record. Do not restate the same generic benefit in every section.
- If the summary looks like task-management software, remove interactive checkboxes, dispatch controls and unsupported state.
- If an illustrative media control looks clickable, either implement its real demonstration behavior or remove its button affordance.
- If the page feels like a stationery brand, increase the scale and fidelity of the actual software representation. If it feels like a dashboard catalog, strengthen the editorial reading hierarchy.

## Craft checks

Compare headline wraps, aligned edges, record readability, visual density, control states, and the compact content order. Evaluate typography at normal reading size. Keep border/radius/shadow values on the named scale. Inspect copy against the truth ledger. Record concrete defect and correction instead of self-awarded quality scores.

## Efficient verification policy

Per owner steering: no large Playwright suite, multi-browser matrix, repeated screenshot loop or new browser testing package for the design foundation. Retain lightweight contrast calculation, source checks, type checks and later a small number of targeted rendered checks if practical. Report unperformed checks honestly. Design and functional requirements remain unchanged.
